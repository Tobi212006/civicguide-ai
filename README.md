# CivicGuide

**A source-linked starting point for exploring official Indian public services.**

CivicGuide is a portfolio project by a BSc Computer Science student interested in responsible AI innovation for public service. It helps visitors find official portals for scholarships, careers, Aadhaar services, and digital government services.

## Current prototype
- Responsive single-page interface with keyword search and category filters.
- No account or personal data collection; results link to official portals.
- No AI model, live government database, application submission, or eligibility checker is connected yet.

## Run locally
Open `index.html` in a modern browser. The app is static and requires no build step or API key.

## Official sources
- [National Scholarship Portal](https://scholarships.gov.in/Students)
- [National Career Service](https://www.ncs.gov.in/)
- [UIDAI](https://uidai.gov.in/en/)
- [UMANG](https://www.umang.gov.in/landing/)

Information and requirements may change; confirm details on each official portal. CivicGuide is an independent student prototype, not affiliated with the Government of India.

## Roadmap
1. Maintain a reviewed service catalogue and last-checked dates.
2. Add accessible Marathi and Hindi interfaces.
3. Explore retrieval-augmented AI over approved official pages, with citations and uncertainty handling.
4. Add link-health checks and a transparent feedback process.

Future AI should ground answers in official sources, link to them, protect privacy, and direct people to the agency for decisions requiring personal details.
